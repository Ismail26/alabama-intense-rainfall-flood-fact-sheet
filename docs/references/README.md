# References

This folder contains literature supporting the Alabama intense-rainfall and flood analysis.

## Included papers

`papers/` contains 14 documents selected from the local `Literature/` collection:

- 13 articles whose PDFs state that they are open access under a Creative Commons Attribution license; and
- NOAA Atlas 14, Volume 9, a U.S. government precipitation-frequency publication.

The papers are provided for research reproducibility. Copyright remains with the respective authors or publishers, and the license statement embedded in each PDF governs reuse. Cite the original publication rather than this repository copy.
