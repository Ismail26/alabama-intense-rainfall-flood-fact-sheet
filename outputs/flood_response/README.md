# Integrated rainfall-flood response outputs

Publishable outputs generated by `Alabama_Integrated_Rainfall_Flood_Response_Pipeline.ipynb`.

- `figures/` contains final flood-response charts and maps.
- `tables/` contains compact frequency-screening, rainfall/flood matching, and flood-impact summaries.
- `reports/` contains fact-sheet priority tables, methodology summaries, and quality-control products.
- `river_network_overlay/` contains compact derived river-network mapping tables and reports.
- `temporal_trends/` contains compact trend-analysis data and reports.

The local source directory is `CRIMSON_AORC_3METHOD/14_flood_response`. Raw API responses, per-gage caches, event hydrographs, checkpoints, Parquet duplicates, and GeoPackages are not published here.
