# Atlas 14 storm-event catalog outputs

Publishable outputs generated by `Alabama_AORC_Atlas14_Storm_Event_Catalog_Pipeline.ipynb`.

- `figures/` contains the final charts and rainfall/flood maps.
- `tables/` contains compact event catalogs, HUC-12 summaries, priority-event tables, and adjacency data.
- `reports/` contains output inventories and compact mapping/report tables.

The local source directory is `CRIMSON_AORC_3METHOD/13_atlas14_event_catalog`. Raw Atlas grids, extraction products, checkpoints, Parquet duplicates, and GeoPackages are not published here. The complete local output set is approximately 1.83 GB and includes GeoPackages larger than GitHub's per-file limit.
