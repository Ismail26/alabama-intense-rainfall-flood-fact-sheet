# Raw data

This directory mirrors the four subfolders supplied under the local project `Data/` directory:

- `ATLAS 14/`
- `Flash Flood/`
- `Flood/`
- `Heavy Rain/`

The folder structure and file contents are preserved for reproducibility. ZIP archives and legacy Excel files are stored with Git LFS; install Git LFS and run `git lfs pull` after cloning to retrieve them.

The two NLDAS text files stored directly at the root of the local `Data/` directory are not part of this subfolder mirror.
