# First GitHub commit

Create an empty GitHub repository named:

`alabama-intense-rainfall-flood-fact-sheet`

Then open a terminal inside this folder and run:

```bash
git init
git status
git add .
git commit -m "Initial project structure and 3-page fact sheet"
git branch -M main
git remote add origin https://github.com/Ismail26/alabama-intense-rainfall-flood-fact-sheet.git
git push -u origin main
```

Before committing, verify that no credentials, large raw datasets, or local-only files are staged.
